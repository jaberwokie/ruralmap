# Iterum Systems — Development Cost-Control Policy

This is a standing instruction for all development work in this repository, across conversations, AI agents, and automated workflows.

## Mandatory operating order
1. **ChatGPT / offline analysis first:** Perform requirements analysis, UX evaluation, architecture, research, design review, troubleshooting, and preparation without invoking credit-consuming Lovable development calls.
2. **GitHub and local tooling next:** Prefer repository inspection, targeted code changes, tests, reviews, and version control when they can accomplish the task safely.
3. **Lovable only when necessary:** Use Lovable's credit-consuming AI editing or generation actions only when the required result cannot reasonably be achieved with the above methods, or the owner explicitly instructs otherwise.

## Spending controls
- Do not interpret available or replenished Lovable credits as authorization to spend them.
- Before a credit-consuming Lovable action, identify the specific required result, why Lovable is necessary, and consolidate related changes into a bounded request.
- Avoid speculative regeneration, iterative cosmetic prompting, repeated retries without diagnosing the failure, and duplicate work already achievable in code.
- Prefer inspecting existing code and gathering evidence before changes; use a focused implementation plan and verify results afterward.
- Distinguish Lovable AI development credits from separate cloud, hosting, integrations, or runtime AI charges.
- Preserve existing GitHub/Lovable synchronization, integrations, databases, deployment state, and production stability; no forced Git history rewrites.
- Never weaken testing, privacy, accessibility, or operational safeguards merely to save credits.
- If cost or necessity is unclear, proceed with non-spending research and identify the blocker rather than initiating a paid Lovable action.

This policy applies to all current and future Iterum Systems development, including Lantern, rural access mapping, Campus for Hope prototypes, and Triad Pathways.
